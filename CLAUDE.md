# Мой корейский: тренажёр по урокам

Статическое веб-приложение (PWA) без сборки: открыть `index.html` или раздать папку любым статическим сервером. Отвечать пользователю по-русски. Переводы слов на русский.

## Структура

```
materials/lesson-XX/01.jpg …   фото страниц урока (исходник, по порядку)
data/index.js                   список уроков: window.LESSON_FILES
data/lessons/lesson-XX.js       содержимое урока: registerLesson({...})
app/                            код: hangul.js, store.js, tts.js, ui.js, keyboard.js (экранная клавиатура), data.js, practice.js, views.js, main.js, styles.css
index.html, manifest.webmanifest, sw.js, icon.svg, icon-*.png (PNG-значки: python tools/make_icons.py)
```

Модули — обычные `<script>` с глобалами (`Hangul`, `Store`, `TTS`, `UI`, `DB`, `Practice`, `Views`), не ES-модули: иначе не работает открытие через `file://`.

## Как добавить урок (главный сценарий)

Пользователь кладёт фото в `materials/lesson-XX/` (или в любую папку, тогда переименовать в `01.jpg`, `02.jpg`… по порядку) и просит «добавь урок N».

1. Прочитать каждое фото. Рукописные пометки пользователя на русском — это его переводы, брать их.
2. Создать `data/lessons/lesson-XX.js` по образцу `lesson-04.js` и дописать id в `data/index.js`.
3. Поля урока:
   - `id`, `number`, `title`, `source` (учебник и страницы), `photos` (число фото), `topics` (что прошли), `notes` (что запомнить, по желанию).
   - `hangul`: какие блоки хангыля открывает урок (`vowels1`, `consonants1`, `vowels2`, `consonants2`, `batchim`, `names` — названия букв, см. `app/hangul.js`).
   - `words`: `{ ko, ru, c }`, где `c` — тема для фильтра словаря (Люди, Профессии, Страны, Еда, Вещи, Места, Природа, Животные, Тело, Время, Действия, Описание, Числа, Служебные). Флаги:
     - `t`: не существительное (`v` глагол или прилагательное, `adv`, `pron`, `excl`, `cnt` счётное слово, `suf` служебное после слова, как 씨, `num` число, как 오 или 삼). Без `t` слово идёт в упражнения на 이에요/예요 и 은/는.
     - `p: 1` — человек (подлежащее в упражнении «X은/는 Y이에요»).
     - `job: 1` — профессия.
   - `phrases`: готовые выражения `{ ko, ru, c }`, из них же упражнение «Собери фразу».
   - `grammar`: `{ id, title, short, body: [html], examples: [{ko, ru}] }`. Генераторы упражнений есть для `copula` (이에요/예요), `topic` (은/는) и `yesno` (ответ «네, …» / «아니요, …이에요» на вопрос «X이에요?»). Для новой грамматики добавить генератор в `GEN` в `app/practice.js` и подключить в `buildPool`.
   - `dialogues`: `{ title, lines: [{ who, ko, ru }], questions: [{ q, a, wrong: [...], at }] }`. `questions` — вопросы на понимание для режима «Прочитай и ответь» (по-русски, `at` — индекс реплики с ответом). Для текстов и диалогов урока их стоит придумать 2–3.
4. Слово, которое уже есть в словаре, повторно добавлять можно: дубликаты по `ko` сливаются, словарь показывает все уроки слова.
5. Запустить `node tools/check-lessons.js` (ошибки и предупреждения по данным), затем проверить в браузере: урок открывается, словарь, тренировка урока без ошибок в консоли.

## Публикация

Сайт выкладывается на GitHub Pages из ветки `main`, корень репозитория. Сайт публичный, поэтому `materials/` (фото учебника) в `.gitignore` и в интернет не попадает. Онлайн вкладки «Конспект» нет (фото не загрузились, и она скрывается), локально фото видны. Приложением могут пользоваться другие люди, поэтому в интерфейсе не должно быть служебных надписей про Claude, папки и личный процесс добавления уроков. После добавления урока: commit и push (только с согласия пользователя), Pages обновится сам за 1–2 минуты.

## Режимы и стиль

Режимы в `MODES` (`app/practice.js`): mix, words, cards (4 оценки как в Anki, `Store.grade`), listen, sounds («Похожие звуки»: слова, отличающиеся одним звуком, `soundAlikes` в `practice.js`, и слоги 가/카/까), hangul, grammar, build (сборка фразы и пропуск слова `cloze`), translate («Составь предложение»: перевод с русского, 은/는 и 이에요/예요 отдельными плашками с парой-обманкой, из фраз уроков и пар человек + профессия), dialog (ролевой диалог по `dialogues`), read («Прочитай и ответь» по `dialogues[].questions`), match (пары на время, отдельный экран `startMatch`), timed (5 минут), numbers (`app/numbers.js`, правило `Numbers.RULE` показывается перед первой тренировкой и по кнопке из разбора), write (прописи на canvas с самооценкой), speak и shadow (Web Speech Recognition, ko-KR), скрытые mistakes и test (контрольная по уроку, 20 вопросов, лучший результат в `Store.getTest`). Новое слово при первой встрече сначала показывается карточкой «Новое слово», проверяется через пару вопросов. В разборе грамматики кнопка «Правило →» (`data-rule="<id грамматики>"`).

Путь по урокам (`DB.path()` в `app/data.js`): текущий урок — последний начатый (новичку первый), следующий предлагается, когда текущий освоен (контрольная от 80% или `DB.mastery` его новых заданий от 0.4). Без `?l=` тренировка идёт по `DB.openNums()` — урокам до текущего, поэтому новичок не получает грамматику до алфавита. Пока прогресса нет, на главной карточка «С чего начать».

Свои слова пользователя: `Store.custom()`, в `DB` это «урок 0» (`DB.allNums()` включает 0, если такие слова есть).

Стиль «Ханок»: тёплое дерево и бумага ханджи (тёмная тема — «ночное небо», сине-серый), акцент нефритовый `--accent`, значок — нефритовая печать, мягкие скругления `--r` / `--r-lg`, корейский шрифт с засечками. Красный `--red` только для ошибок и печатей 도장 (`UI.stamp`, календарь). Клетки 원고지 остались в прописях и разборе ошибок. Не добавлять градиенты, тени, эмодзи, иконки в цветных плашках.

## Прогресс

`localStorage`, ключ `hangul-study-v1`. Ключи заданий: `w:<ko>` (слово или фраза), `j:<буква>`, `b:<слово>` (патчим), `g:copula:<ko>`, `g:topic:<ko>`, `g:sent:<p>|<job>`, `build:<фраза>`, `cloze:<фраза>`, `tr:<предложение>`, `dl:<реплика>`, `write:<цель>` / `write:j:<буква>`, `speak:<ko>`, `shadow:<фраза>`, `rd:<вопрос>`, `num:<s|n>:<small|mid|big>` (числа по диапазонам, не по каждому числу). «Мои ошибки» собираются из ключей хранилища через `resolveKey` в `practice.js`: новый тип ключа надо добавить туда.

Всё, что читается из хранилища, ссылки переноса и файла, проходит через `clean()` в `store.js` (типы, пределы, отброс лишнего). Не вставлять в HTML значения в обход `esc()` и не ослаблять `clean()`: ссылку переноса может прислать кто угодно. Перенос между устройствами: ссылка `#/import/<сжатый прогресс>` (`Store.pack` / `Store.unpack` / `Store.merge`). Не переименовывать ключи без миграции, иначе пропадёт прогресс. Интервалы повторения: коробки 0–6, 0/1/2/4/8/16/32 дня.

Чтение слова: `Hangul.pron` в `app/hangul.js` (связное чтение, ㅎ, назализация, ㄹ, напряжение). Показывается в скобках через `UI.rr` / `UI.pr`, если отличается от написания.
